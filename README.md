# 🌤️ Weather Dashboard

A beautiful, modern weather dashboard built with vanilla HTML, CSS, and JavaScript.

![Dark themed weather dashboard](https://img.shields.io/badge/theme-dark-0f172a) ![OpenWeatherMap](https://img.shields.io/badge/API-OpenWeatherMap-orange)

## Features

- 🔍 **City Search** — Look up weather for any city worldwide
- 🌡️ **Current Conditions** — Temperature, feels-like, high/low, and weather description
- 💧 **Detail Cards** — Humidity, wind, pressure, visibility, cloudiness, and coordinates
- 🌅 **Sunrise/Sunset** — With an animated sun-arc position indicator
- 🔄 **Unit Toggle** — Switch between °C and °F on the fly
- 🎮 **Demo Mode** — Try it without an API key using sample data

## Getting Started

### 1. Get an API Key

1. Sign up for free at [OpenWeatherMap](https://home.openweathermap.org/users/sign_up)
2. Get your API key from [your account](https://home.openweathermap.org/api_keys)

### 2. Open the Dashboard

Simply open `index.html` in your browser — no build tools or server needed.

### 3. Enter Your API Key

Paste your API key when prompted, or click **"Use Demo"** to explore with sample data.

## Tech Stack

- **HTML5 / CSS3 / JavaScript** — Zero dependencies
- **OpenWeatherMap API** — Free tier for current weather data
- **Responsive Design** — Works on desktop, tablet, and mobile
